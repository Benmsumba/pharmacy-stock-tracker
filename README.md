# Pharmacy Stock & Expiry Tracker

A browser-only portfolio demo for monitoring fictional pharmacy batches. Add or edit batches, filter by stock or expiry status, and reload to verify local persistence.

Open index.html in a browser or serve the project directory with any static web server. There are no build dependencies. Dates use the browser's local calendar day. Low stock means at most 10 units, and expiring soon means today through the next 30 days.

The app is a demonstration with fictional inventory. It stores edits in local browser storage.
